# Kaliber Coaching – hemsida

## Så uppdaterar du sidan

1. Gå till **app.pagescms.org** och logga in med ditt GitHub-konto.
2. Välj projektet **kaliber-coaching**.
3. **Klientresultat:** klicka på *Lägg till*, ladda upp bilderna (den första visas på kortet), skriv gärna namn och en kort text och tryck *Spara*. Dra korten för att ändra ordningen.
4. **Texter och inställningar:** här ändrar du all text, Calendly-länken och butikslänken.
5. Sidan uppdateras automatiskt inom 1–2 minuter efter att du sparat.

**Tips för bilder:** stående format 4:5 (till exempel 1080 × 1350) ser bäst ut. Ladda bara upp bilder på klienter som har godkänt att synas.

## Merch

När butiken finns (Shopify, Printful eller liknande): gå till *Texter och inställningar → Inställningar*, klistra in butikens adress och bocka i *Visa butikslänk i menyn*.

## Filer

- `content/site.json` – alla texter och inställningar
- `content/results.json` – klientresultaten
- `assets/img/` – bilder
- `index.html`, `css/`, `js/` – själva sidan (behöver inte röras)
